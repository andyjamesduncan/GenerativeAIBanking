## Workshop 3.3: Excel VBA Macro – Automating Risk & Portfolio Reporting

### Important Note

If you cannot download/upload ﬁles on your system or save Excel ﬁles as Macro-Enabled ﬁles, or Enable Macros when opening an Excel ﬁle, then please treat this workshop as a demonstration.

### Instruction Text

Step 1

If possible and allowable in your environment, download the Portfolio_Workshop_File.xlsx ﬁle to a system you are allowed to download into, where you are also allowed to save Excel ﬁles as Macro-Enabled ﬁles. This will be your starting work ﬁle.

Step 2

Open the Portfolio_Workshop_File.xlsx Excel ﬁle and save it as a Macro-Enabled Excel ﬁle with a digerent ﬁlename, such as Portfolio_Workshop_File_v02.xlsm. We will assume that name for the rest of this workshop.

Step 3

Ensure that you have ‘Developer’ enabled in your version of Excel. You will ﬁnd a guide on how to do this in the appendix of this Workbook ﬁle.

Step 4

Go to a new ChatGPT chat session and upload the Portfolio_Workshop_File_v02.xlsm ﬁle into an input box.

Step 5

In the same input box, now input the following prompt text into ChatGPT and execute the prompt. Copy the code produced.

### Copy Text

> You are a senior Excel VBA developer.
>
> Write production-quality VBA code that: 
> - Uses Option Explicit
> - Avoids Type Mismatch errors
> - Uses Variant when using Application.Match 
> - Checks IsError before assigning to numeric variables 
> - Uses the ActiveWorksheet (do not hard-code sheet names) 
> - Dynamically detects the header row (search first 5 rows) 
> - Accepts flexible header names: 
> - Price column may be: “Price”, “Unit Price”, or “PRICE” 
> - Quantity column may be: “Quantity”, “Qty”, or “QUANTITY” 
> - If headers are not found, prompt the user to select the Price and Quantity columns manually 
> - Prevent duplicate “Market Value” columns 
> - Include full structured error handling
>
> The macro must: 
> - Loop through rows 
> - Calculate Price × Quantity 
> - Write to column “Market Value” 
> - Display total portfolio value 
> - Place total portfolio value two rows below the final market value calculated 
> - Place the phrase “Total Portfolio Value” in the cell one column to the left and right-align that label
>
> The code must compile and run without Type Mismatch errors.
>
> Keep the code clear and well-commented.

### Instruction Text

Step 6

Now open the Portfolio_Workshop_File_v02.xlsm and Enable Macros. From the enabled ‘Developer’ tab, go to the ‘Visual Basic’ coding environment and create a new VBA module by selecting Insert → Module.

### Instruction Text

Step 7

In the new module, paste your copied VBA code generated inside ChatGPT. Make a note of the main name of the function generated, then close the Visual Basic environment and go back to the main Excel worksheet.

Step 8

From the ‘Developer’ tab, choose the macro that you just pasted into the Visual Basic Module and execute that macro.

# Appendix

## Enabling Developer Mode in Excel

This guide explains how to enable the Developer tab in Microsoft Excel on both Windows PC and Mac.

The Developer tab is required to:

• Open the VBA editor
• Insert macros
• Record macros
• Insert form controls

### Part 1 – Windows PC

Step 1 – Open Excel

Open Microsoft Excel (any workbook is fine).

Step 2 – Open Excel Options

• Click File • Click Options (bottom left)

Step 3 – Customize the Ribbon

• In the Excel Options window • Click Customize Ribbon

Step 4 – Enable Developer

• In the right-hand panel (Main Tabs) • Tick the checkbox labelled Developer

Step 5 – Conﬁrm

• Click OK

You should now see Developer in the top ribbon. Opening the VBA Editor (Windows) Once Developer is enabled:

• Click Developer • Click Visual Basic

Shortcut:

• Press ALT + F11

### Part 2 – Mac (Excel for macOS)

Step 1 – Open Excel

Open Microsoft Excel.

Step 2 – Open Preferences

• Click Excel in the top menu bar • Click Settings (or Preferences, depending on version)

Step 3 – Open Ribbon & Toolbar Settings

• Click Ribbon & Toolbar

Step 4 – Enable Developer

• In the right-hand panel under Main Tabs • Tick the checkbox for Developer

Step 5 – Conﬁrm

• Click Save

The Developer tab will now appear in the ribbon. Opening the VBA Editor (Mac) • Click Developer • Click Visual Basic

Shortcut:

• Press Fn + Option + F11 (On some keyboards: Option + F11)

### Common Issues

Developer tab not visible after ticking it?

Restart Excel.

VBA Editor won’t open?

Ensure macros are enabled:

• Windows: File → Options → Trust Center → Trust Center Settings → Macro Settings • Mac: Excel → Settings → Security & Privacy → Macro Security
