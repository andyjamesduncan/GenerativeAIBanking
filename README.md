# Generative AI in Finance and Banking

This repository contains materials, examples, and exercises used in the  
**Redcliffe Generative AI in Finance and Banking Course**.

## Purpose

The repository supports course participants with:

- Practical AI use cases in banking
- Regulatory and compliance examples
- Portfolio and credit analysis applications
- VBA and Python demonstrations
- Structured prompting techniques

## Requirements

- Excel (for VBA components)
- Basic familiarity with finance and risk concepts
